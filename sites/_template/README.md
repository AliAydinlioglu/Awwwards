# Awwwards Site Starter Template

A modular, lightweight starter with:
- Fluid 60fps lerped scroll loop
- Active sticky guardian (zero black-screen bugs)
- Scene card fading & timeline gauge
- Dark modern design system tokens
- Pre-configured responsive typography

## Quickstart to create a new site:
Run from the root directory:
```bash
npm run new my-new-site
```
Or simply copy this folder:
```bash
cp -r sites/_template sites/my-new-site
```
Then visit:
```text
http://localhost:8080/sites/my-new-site/
```
